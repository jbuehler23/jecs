## Recommended Books

### Game Development

1. **Game Engine Architecture** - Jason Gregory
   - Comprehensive overview of all engine systems
   - Industry-standard reference (used at Naughty Dog)

2. **Game Programming Patterns** - Robert Nystrom
   - Design patterns for games (Command, Observer, Component, etc.)
   - Free online: [gameprogrammingpatterns.com](https://gameprogrammingpatterns.com/)

3. **Real-Time Rendering, 4th Edition** - Akenine-Möller et al.
   - Definitive graphics programming reference
   - Covers lighting, shadows, PBR, ray tracing

4. **Foundations of Game Engine Development** - Eric Lengyel (Series)
   - Volume 1: Mathematics
   - Volume 2: Rendering
   - Deep technical dives

### Performance

5. **Java Performance, 2nd Edition** - Scott Oaks
   - JVM internals, GC tuning, profiling

6. **Optimizing Java** - Benjamin Evans et al.
   - Modern Java performance techniques

7. **Data-Oriented Design** - Richard Fabian
   - Free: [dataorienteddesign.com/dodbook](http://www.dataorienteddesign.com/dodbook/)

## Where to Go Next

After completing this tutorial series:

1. **Build a game** with your engine (best way to find missing features)
2. **Add networking** for multiplayer
3. **Implement scripting** for rapid development
4. **Optimize** with profiling and benchmarks
5. **Share your engine** on GitHub
6. **Write blog posts** about your journey
7. **Join game jams** to stress-test your engine

---

## Final Words

Game engine development is a marathon, not a sprint. You'll continually learn and improve. Key tips:

- **Start small**: Basic renderer → Add features incrementally
- **Profile early**: Performance issues compound
- **Study others**: Read source code of mature engines
- **Build games**: Use your engine to find what's missing
- **Stay curious**: Graphics/systems programming evolves constantly

**Good luck on your game engine journey!**
